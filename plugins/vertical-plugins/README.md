# Vertical plugins

Skill, slash-command, safety-hook, and MCP server bundles that attach **directly to the main agent**, with no sub-agent hand-off. Install a vertical when you want a specific AWS operational capability (such as VPC design, EKS/ECS troubleshooting, database tuning, or FinOps right-sizing) directly in your primary session; install the matching [agent plugin](../agent-plugins) when you want an isolated specialist sub-agent instead.

```bash
claude plugin install aws-networking@talkops-devops-plugins
```

Skills activate automatically from their descriptions, or explicitly with `/<plugin>:<skill>`. Slash commands execute structured multi-step operational workflows with `/<plugin>:<command>`.

## Notes

- **Safe by default.** Every vertical plugin bundles `secret-safety.py` and `aws-mutation-gate.py` (`PreToolUse` hooks) to prevent accidental credential exposure and require confirmation before mutating AWS resources.
- **One `aws-mcp` per plugin.** Each vertical is self-contained. If you install several verticals simultaneously, toggle duplicate `aws-mcp` instances off in `/mcp`.
- **Authoring & validation.** All vertical plugins are maintained directly under `plugins/vertical-plugins/<name>/` and validated with `python3 scripts/validate_plugins.py`. See [docs/authoring-agent-plugins.md](../../docs/authoring-agent-plugins.md#vertical-plugins).
