# STRIDE to AWS Controls Mapping Matrix (Preventative, Detective, Responsive)

| STRIDE Category | Common AWS Cloud & GenAI Attack Vectors | Preventative Controls (IAM / Network / Crypto) | Detective Controls (Audit / Threat Intel) | Responsive & Recovery Controls |
|---|---|---|---|---|
| **S — Spoofing** | Stolen IAM access keys, forged webhook calls, confused-deputy cross-service role assumption, spoofed MCP agent identity | Disable IAM user access keys; OIDC federation (`aws:RequestTag`); `aws:SourceArn` & `aws:SourceAccount` on service trust policies; `aws:CalledViaAWSMCP` condition key; API Gateway Cognito/JWT/SigV4 authorizers; mTLS via ACM Private CA | CloudTrail `ConsoleLogin` without MFA, GuardDuty `UnauthorizedAccess:IAMUser/*`, IAM Access Analyzer external access findings | Revoke active STS sessions via inline deny policy (`aws:TokenIssueTime`); rotate Secrets Manager secrets immediately |
| **T — Tampering** | Unauthorized modification of S3 objects, DynamoDB records, container images in ECR, CloudFormation templates, or transit payloads | S3 Object Lock (Governance/Compliance mode); ECR image tag immutability + Cosign/Notation signing; TLS 1.3 (`aws:SecureTransport: true`); VPC Endpoint policies | CloudTrail log file integrity validation (`EnableLogFileValidation: true`); AWS Config configuration drift rules; S3 Server Access Logs | CloudFormation Stack rollback / drift remediation; S3 Versioning restoration; AWS Backup immutable vault restore |
| **R — Repudiation** | Unattributed administrative mutations, deleted CloudTrail logs, shared database superuser credentials, unlogged AI agent tool calls | Separate IAM roles per service/operator; `sts:SourceIdentity` propagation; RDS IAM Database Authentication; SCP denying `cloudtrail:StopLogging` / `DeleteTrail` | Multi-region Organization CloudTrail trail writing to centralized Log Archive account with KMS CMK; Aurora Advanced Auditing / PostgreSQL `pgaudit` | Immutable legal-hold audit logs in S3 Glacier Vault Lock / Object Lock |
| **I — Information Disclosure** | Public S3 buckets/RDS snapshots, SSRF to EC2 IMDSv1 (`169.254.169.254`), plaintext secrets in Lambda env vars or `.tfstate`, cross-tenant RAG leakage | S3 Account-level Block Public Access; IMDSv2 enforced (`HttpTokens: required`, hop limit `1`); KMS CMK encryption + `kms:ViaService`; Secrets Manager dynamic references; tenant-filtered Bedrock Knowledge Base metadata | Amazon Macie sensitive data discovery; GuardDuty `Exfiltration:S3/*`; IAM Access Analyzer unused/public access findings | Automated S3 public-block remediation via EventBridge; KMS key grant revocation |
| **D — Denial of Service** | Layer-7 HTTP floods, wallet-denial (unbounded Lambda/Bedrock invocations), RDS connection exhaustion, noisy-neighbor partition throttling | AWS Shield Advanced + WAFv2 Rate-Based Rules; CloudFront edge caching; API Gateway throttling + usage plans; Lambda `ReservedConcurrentExecutions`; RDS Proxy; SQS buffering | CloudWatch `HTTPCode_ELB_5XX_Count`, WAF `BlockedRequests`, Cost Anomaly Detection alerts, Service Quotas >75% utilization alarms | Route 53 ARC Zonal Autoshift; Auto Scaling target tracking; WAF CAPTCHA/Block rule activation |
| **E — Elevation of Privilege** | `iam:PassRole` + `lambda:CreateFunction` / `ec2:RunInstances` privilege escalation, container breakout on EKS/ECS, indirect prompt injection triggering mutating agent tools | IAM Permissions Boundaries on all delegated role creation; SCP/RCP guardrails; EKS Pod Identity (`pods.eks.amazonaws.com`) with `runAsNonRoot: true` & read-only rootfs; `aws-mutation-gate.py` + `aws:ViaAWSMCPService` read-only deny | GuardDuty Runtime Monitoring (EKS/ECS/EC2) privilege escalation findings; CloudTrail `AttachRolePolicy` / `PutRolePolicy` event alarms | Isolate compromised instance/pod security group to forensic quarantine SG; terminate compromised task/pod |
