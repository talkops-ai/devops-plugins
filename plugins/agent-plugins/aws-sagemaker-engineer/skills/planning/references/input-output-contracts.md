# Input-Output Contracts

| Skill | Inputs and Prerequisites | Outputs | Restrictions & Scope |
|---|---|---|---|
| **planning** | User's goal (conversational) | `PLAN.md` | Orchestrates both Serverless FM Customization workflows and the 5-Stage Architectural Decision Engine |
| **sagemaker-solution-architect** | Business problem, data modality, scale, latency/SLA, compliance requirements | `ARCHITECTURE.md` (compute tier triage, inference topology, Well-Architected ML tradeoff matrix) | Evaluates when to skip SageMaker (for Bedrock/Lambda/KServe) and selects Tier A (Autopilot), Tier B (Serverless FM), Tier C (Managed Training), or Tier D (HyperPod) |
| **sagemaker-domain-vpc-iac** | `ARCHITECTURE.md` or platform security requirements | CDK (TypeScript/Python) or CloudFormation L1 templates (`CfnDomain`, `CfnUserProfile`, `CfnSpace`, `CfnImage`, VPC endpoints, KMS, IAM), validated via `awsiac` | Uses L1 `Cfn*` constructs (`aws-cdk-lib/aws-sagemaker` has no L2 Domain/Space constructs). Enforces `VpcOnly` PrivateLink + NFS 2049 + self-referencing SG rules |
| **sagemaker-cost-estimator** | Planned compute resources (instances, duration, storage, endpoints) + AWS region | `COST_ESTIMATE.md` backed by live `awspricing` MCP queries | Must query live prices via `awspricing` MCP server (`AmazonSageMaker`, `AmazonEC2`, `AmazonEFS`, `AmazonFSx`, `AmazonS3`, `AmazonBedrock`); compares Spot, Trainium/Inferentia, and `InferenceComponent` Scale-to-Zero |
| **directory-management** | None | Project directory | None |
| **signing-in-to-aws** | None | Configured AWS CLI / SSO credentials | None |
| **use-case-specification** | Problem statement, primary users, success tenets, deployment constraints, and quantitative SLAs | `use_case_spec.md` | Captures Success Tenets (fine-tuning), Deployment Constraints (base model deployment), and Quantitative SLA & Architecture Constraints (p99 latency, RPS, modality, budget) |
| **model-selection** | `use_case_spec.md` | For deployment: `model_id` (Hub ID), `instance_type`, `inference_config_name`, EULA gating status. For fine-tuning: base model name + EULA status | Includes Architectural Triage Gate: routes Tabular/Time-Series to `sagemaker-training-architect` (Autopilot/Canvas) and Custom Vision/Multimodal to `sagemaker-training-architect` (Estimators) |
| **sdk-getting-started** | None | Verified environment (`sagemaker>=3.17.0,<4.0`, region, execution role, platform checks) | Includes Apple Silicon `x86_64-apple-darwin` check for `awsiac`/`cfn-guard` and Windows `uvx` guidance |
| **finetuning-technique** | Base model name; `use_case_spec.md` | Confirmed technique (`SFT`, `DPO`, `RLVR`, `RLAIF`) | Checks recipe compatibility for Serverless Model Customization |
| **dataset-evaluation** | Dataset file path; for training data: `finetuning-technique` and `model-selection` | Validation result | Evaluation datasets do not require the technique to be known |
| **dataset-transformation** | Dataset file path; output location; for training data: `finetuning-technique` and `model-selection` | Transformed dataset file path | All dataset schema conversions for FM customization must go through this skill |
| **finetuning** | `use_case_spec.md`; `model-selection`; `finetuning-technique`; training dataset (S3); verified environment | Serverless customization training job name/ARN | Supported regions: `us-west-2`, `us-east-1`, `ap-northeast-1`, `eu-west-1`. For non-serverless or custom training, delegates to `sagemaker-training-architect` or `hyperpod-Training` |
| **sagemaker-training-architect** | `ARCHITECTURE.md` or training requirements; dataset S3 URI; verified environment | Training scripts, SDK v3 `@remote` / Estimator / Autopilot AutoMLv2 code, distributed DDP/FSDP/Spot configs | Covers standard Managed Training Jobs, custom PyTorch/HF/XGBoost/Vision (SAM), Managed Spot + checkpointing, FastFile/FSx Lustre, and Autopilot v2 |
| **model-evaluation** | Training job name/ARN or base model ID; evaluation dataset | Evaluation metrics (LLM-as-a-Judge or Custom Scorer) | LLM-as-Judge and built-in scorers are not supported for Nova models |
| **model-deployment** | Serverless LoRA training job ARN OR `model-selection` JumpStart deploy config (`model_id`, `instance_type`, `inference_config_name`) | Endpoint or Bedrock model ARN; or benchmark/recommendation report | Covers Serverless LoRA → SageMaker/Bedrock, JumpStart base model → SageMaker, and endpoint benchmarking/recommendations. Delegates custom/FFT/InferenceComponent/Serverless/Async/Batch to `sagemaker-inference-architect` |
| **sagemaker-inference-architect** | Model artifacts (S3/ECR/JumpStart/HF) or `ARCHITECTURE.md`; latency/throughput SLAs | Production inference code/IaC (`InferenceComponent` packing, Scale-to-Zero, MCE, MME, LMI/vLLM/Neuron, Serverless, Async, Batch Transform, Bedrock CMI) | Covers all SageMaker AI hosting patterns and multi-model bin-packing with `RoutingConfig: LEAST_OUTSTANDING_REQUESTS` |
| **sagemaker-mlops-pipelines** | Training/evaluation/deployment steps or governance requirements | SageMaker Pipelines DAG (`@step`, `Pipeline`), Feature Store (`CfnFeatureGroup`), Model Registry (`ModelPackageGroup`), CI/CD workflows | Integrates with `manage-mlflow` for experiment tracking and `querying-aws-sagemaker-catalog` for Unified Studio catalog governance |
| **manage-mlflow** | AWS region, IAM role ARN, S3 bucket URI | SageMaker Managed MLflow App ARN (`CreateMlflowApp`, `ListMlflowApps`, `UpdateMlflowApp`, `DeleteMlflowApp`) | Uses serverless MLflow App APIs (`CreateMlflowApp`), never legacy `CreateMlflowTrackingServer` |
| **querying-aws-sagemaker-catalog** | DataZone domain ID, AWS region, Athena workgroup | SQL governance queries and analytics over `s3tablescatalog/aws-sagemaker-catalog`.`asset_metadata`.`asset` | Always filter by `snapshot_time` (`WHERE DATE(snapshot_time) = CURRENT_DATE`) |
| **sagemaker-observability-governance** | Endpoint name, baseline dataset S3 URI, SLA thresholds | Deployment Guardrails (Blue/Green Canary/Linear, auto-rollback, shadow variants), Model Monitor schedules (Data/Model/Bias/Explainability), CloudWatch alarms | Coordinates with `endpoint-diagnostics` and `cloudwatch` MCP server for live incident triage |
| **endpoint-diagnostics** | Endpoint name, AWS region | Structured diagnostic report (`DescribeEndpoint`, CloudWatch metrics, container logs via `collect_diagnostics.py`) | Read-only deterministic collection for deployed endpoints |
| **hyperpod-cluster-debugger** | HyperPod cluster name/ARN, AWS region | Cluster health, CloudFormation stack status, EKS/Slurm control plane diagnostics | Uses `sagemaker` MCP `manage_hyperpod_stacks` and `manage_hyperpod_cluster_nodes` |
| **hyperpod-node-debugger** | HyperPod cluster name, node IDs | Instance health, hardware failure checks, node replacement/software update actions | Mutating node operations (`update_software`, `batch_delete`) gated by `aws-mutation-gate.py` |
| **hyperpod-nccl** | HyperPod cluster name, training job logs | EFA / NCCL collective communication timeout and topology diagnostics | None |
| **hyperpod-performance-debugger** | HyperPod cluster name, training metrics | GPU utilization, FSx for Lustre / S3 I/O bottleneck, and step-time profiling | None |
| **hyperpod-slurm-debugger** | Slurm cluster nodes, job IDs | `sinfo`/`squeue`/`scontrol` Slurm scheduler and prolog/epilog failure analysis | None |
| **hyperpod-ssm** | HyperPod cluster name, instance ID | Secure Systems Manager (`aws ssm start-session`) node inspection | None |
| **hyperpod-version-checker** | HyperPod cluster name | AMI, driver, EFA, and HyperPod software version compatibility audit | None |
| **hyperpod-issue-report** | Diagnostic outputs from `hyperpod-*` skills | Structured root-cause and AWS Support escalation report | None |
