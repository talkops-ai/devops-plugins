# Agent plugins

Self-contained AWS specialist sub-agents. Each plugin bundles one named specialist agent (`agents/<name>.md` for Claude Code and `codex/agents/<name>.toml` for Codex) along with its domain skills, slash commands, deterministic safety hooks, and MCP servers.

```bash
claude plugin install aws-sre-agent@talkops-devops-plugins
```
