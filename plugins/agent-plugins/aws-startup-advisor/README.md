# AWS Startup Advisor

Principal AWS Startup Solutions Architect & Fractional Startup CTO: stage-calibrated architecture and unit-economics guidance (Pre-Revenue/MVP through Series B+), AWS Activate credit runway & 26-point account security/spend-leak audits, vibe-coded prototype migrations (Lovable, Bolt.new, Replit, v0), GCP/Azure/Heroku-to-AWS migrations, provider-neutral AI/LLM & OpenRouter migrations to Amazon Bedrock (`bedrock-mantle` GPT-5.x & Converse), deterministic AI agent runtime selection (AgentCore, ECS, EKS, Lambda, MicroVMs, Temporal), DevOps Agent operations, and AWS Activate offers.

## Install

| Host | How |
|---|---|
| Claude Code | `/plugin marketplace add talkops-ai/devops-plugins`, then `/plugin install aws-startup-advisor@talkops-devops-plugins` |
| Codex | `codex plugin marketplace add talkops-ai/devops-plugins`, then install from the Plugins Directory; for the agent persona, copy [`codex/agents/aws-startup-advisor.toml`](./codex/agents/aws-startup-advisor.toml) to `~/.codex/agents/` |
| Other Agent Plugins hosts | Load this directory; [`plugin.json`](./plugin.json), `skills/`, and [`mcp.json`](./mcp.json) follow the portable [Agent Plugins](https://agent-plugins.org) format |

## Agent

This is an **agent plugin**: every skill, command, hook, and MCP server below is bound to the [`aws-startup-advisor`](./agents/aws-startup-advisor.md) agent, which the host runtime spawns as a dynamic sub-agent.

- Claude Code: `@agent-aws-startup-advisor:aws-startup-advisor` or let Claude delegate based on the agent description
- Headless: `claude --agent aws-startup-advisor:aws-startup-advisor`
- Codex: install the custom agent above, then ask Codex to spawn `aws-startup-advisor`. Codex plugins can't bundle agents, so without it the skills and MCP servers attach to the main agent.

Dispatched by the orchestrating agent's skills; not meant for direct conversation.

- `aws-startup-advisor:generic-phase-worker-rwx` — Generic, phase-AGNOSTIC worker that runs ONE migration phase's work (its fragments + assembler) in an isolated context and writes the phase's artifact(s) to di…
- `aws-startup-advisor:llm2bedrock-code-analyzer` — Analyze the local source repo, detect the AI framework and LLM SDK usage, map all call sites, identify prompts, and enumerate user-visible behavior-deltas for…
- `aws-startup-advisor:llm2bedrock-code-rewriter` — Rewrite LLM SDK calls to Amazon Bedrock on a dedicated git branch, swap dependencies, generate tests, and apply the user-confirmed behavior-delta decisions.
- `aws-startup-advisor:llm2bedrock-log-ingestor` — Parse LLM API logs from the local repo, extract prompt/response pairs, and build a golden dataset (prompts.jsonl) for evaluation.
- `aws-startup-advisor:llm2bedrock-prompt-evaluator` — Run each golden prompt against the target Bedrock model via the pinned uv harness, score with LLM-as-judge, and report a pass rate.

## MCP servers

Declared in [`.mcp.json`](./.mcp.json) (Claude Code) and [`mcp.json`](./mcp.json) (portable). In Claude Code they are bound to the agent through its `tools:` allowlist.

| Server | Transport | Launch | Claude Code tool pattern | Notes |
|---|---|---|---|---|
| `aws-mcp` | stdio | `uvx mcp-proxy-for-aws-cli==1.7.0` `--metadata` | `mcp__plugin_aws-startup-advisor_aws-mcp__*` |  |
| `aws-pricing` | stdio | `uvx awslabs.aws-pricing-mcp-server@latest` | `mcp__plugin_aws-startup-advisor_aws-pricing__*` |  |
| `aws-billing` | stdio | `uvx awslabs.billing-cost-management-mcp-server@latest` | `mcp__plugin_aws-startup-advisor_aws-billing__*` |  |

AWS credentials are inherited from the host environment (`AWS_PROFILE`, SSO, or instance role). In Claude Code `AWS_REGION` defaults to `us-east-1` when unset; the portable `mcp.json` can't express that default, so set `AWS_REGION` in your environment on other hosts. Codex starts MCP servers with a minimal environment: if a server can't see your profile, set `AWS_PROFILE`/`AWS_REGION` for it in `~/.codex/config.toml`.
