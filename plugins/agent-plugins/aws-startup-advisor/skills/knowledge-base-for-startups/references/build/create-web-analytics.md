## Create Web Analytics (Iceberg on AWS)

- **Summary:** Collect web logs with API Gateway and store them in S3 through Amazon Kinesis
- **AWS Services Used:** AWS Amplify, Amazon API Gateway, Amazon Kinesis, Amazon S3
- **Deployment Method:** Implementation guide
- **Estimated Time:** 3 hours 45 minutes
- **Cost Calculator:** https://calculator.aws/
- **Get Started:** https://docs.aws.amazon.com/apigateway/latest/developerguide/integrating-api-with-aws-services-kinesis.html

## Overview

In this guide, you will learn about the AWS Amplify core modules including the Amplify CLI, Amplify Studio, Amplify Hosting, authentication (using Cognito) and integrating Amplify into a React web application. In addition you will learn to integrate and use weeb analytic services into Amplify applications, create email campaigns, setup recommendations and setup analytic dashboards.
