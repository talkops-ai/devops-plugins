## Overview

In this hands-on workshop, you will learn how to accelerate development with Anthropic's agentic coding assistant integrated on Amazon Bedrock. You'll discover how to configure, use, and maximize Claude Code's capabilities to transform coding workflows, making code writing, debugging, testing, and project management more efficient. Additionally, you'll learn advanced deployment patterns for Claude agents using the Agent SDK on Amazon Bedrock AgentCore Runtime. The workshop emphasizes best practices from Anthropic to help you get the most out of this powerful AI coding assistant.

This CDK asset provides a production-ready Claude API proxy that automatically falls back to AWS Bedrock when Anthropic API rate limits are encountered. Built on ECS Fargate with Application Load Balancer, it offers high availability and seamless failover to ensure uninterrupted AI-powered coding workflows for your entire team. The solution includes intelligent rate limit tracking via DynamoDB, and comprehensive token usage monitoring. Deploy this infrastructure in minutes to eliminate API disruptions and provide a reliable, scalable Claude coding assistant experience across your organization.
