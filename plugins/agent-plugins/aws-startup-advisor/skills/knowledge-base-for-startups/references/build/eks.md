## Overview

Amazon Elastic Kubernetes Service (Amazon EKS) enables teams of any size or skill level to build, run, and scale production-ready applications easily across any environment. In this workshop you'll get hands-on experience in building and deploying container platforms on Amazon EKS using Amazon EKS Blueprints for CDK. You will gain practical knowledge of defining, configuring, and managing Kubernetes environments through infrastructure as code. Upon completion, you will have acquired valuable skills in defining and deploying Amazon EKS clusters using EKS Blueprints methodologies.

Amazon Elastic Kubernetes Service (Amazon EKS) enables teams of any size or skill level to build, run, and scale production-ready applications easily across any environment. In this workshop, you'll gain hands-on experience implementing various auto scaling strategies in EKS environments. You will learn practical techniques to automatically adjust resources based on demand, ensuring optimal performance and cost efficiency for your containerized applications. Upon completion, you will have acquired valuable skills in configuring and managing different auto scaling mechanisms in Amazon EKS.
