# Partner-built plugins

Plugins that wrap third-party DevOps products (observability, incident management, CI/CD, IaC tooling). They use the vendor's official skills and MCP servers, follow the vendor's conventions, and keep the vendor's name, author, and license.

| Plugin | Vendor | License | What it holds |
|---|---|---|---|
| [`terraform`](./terraform) | HashiCorp | MPL-2.0 | All 16 official HashiCorp Terraform skills: configuration style, modules, tests, search/import, Stacks, policy, Azure Verified Modules, and provider development. The Terraform registry MCP server is an optional connector. |

Like the AWS plugins, partner-built plugins are generated by `scripts/sync_aws_plugins.py` from entries with `"kind": "partner"` in `scripts/aws-plugin-map.json`. Vendor content is copied unmodified. Each plugin ships the Claude Code, portable Agent Plugins, and Codex layouts.

To add one, follow the standards in [docs/authoring-agent-plugins.md](../../docs/authoring-agent-plugins.md#partner-built-plugins).
