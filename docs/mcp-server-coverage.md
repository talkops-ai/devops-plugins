# MCP server coverage

How each server in [awslabs/mcp](https://github.com/awslabs/mcp) is used by the TalkOps AWS plugins: **35 bundled**, **11 connectors**, **16 not used** (62 total).

- **Bundled** servers are declared in the plugin's `.mcp.json` (Claude Code) and `mcp.json` (portable Agent Plugins format, read by Codex and other hosts) and start when the plugin is enabled. They need only AWS credentials, and default to read-only where the server supports it.
- **Connectors** need a connection target (endpoint, host, credentials secret, or local runtime) at startup. Plugins document them in `CONNECTORS.md` with Claude Code (`claude mcp add`) and Codex (`codex mcp add` / `config.toml`) snippets. Plugin MCP files have no reliable "disabled" switch across hosts (Claude Code ignores it; the portable schema has none), so they are never shipped disabled.
